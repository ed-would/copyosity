# Resizable overlay panel — quick test guide

No seed data required.

## Resize

1. Open the clipboard overlay (`⌘⇧V` or tray menu).
2. Drag the corner grip:
   - **Horizontal board** — bottom-right grip (width; height is fixed).
   - **Vertical board** — bottom-left grip (width of the docked strip).
3. Close and reopen the overlay — size should persist across sessions.

## Reset

**Settings → History → Restore default size**

## Related

- Command palette has its own resize grip and min size (480×220) — separate from the overlay panel.
